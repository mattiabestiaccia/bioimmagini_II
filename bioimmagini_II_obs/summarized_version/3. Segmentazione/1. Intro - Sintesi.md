# Introduzione alla Segmentazione - Sintesi

## Definizione

- **Segmentazione** (pattern recognition): operazione di **medio livello**
- Estrazione ROI (Regioni di Interesse) dall'immagine
- Associare a strutture anatomiche una lista di pixel/voxel con **etichetta (label)**

## Modello Immagine

$$I(x,y) = \{[I_o(x,y) + n_B(x,y)] * h(x,y)\} g(x,y) + n(x,y)$$

**Obiettivo**: estrarre $I_o$ dall'immagine reale $I$

## Problematiche

- **Indeterminatezza**: fattori di corruzione solo parzialmente noti
- **Dipendenza clinica**: pattern dipendono dal quesito diagnostico
- **Specificità**: estrazione di numero limitato di strutture

## Rappresentazioni del Risultato

### Maschera (Mask)
- Immagine binaria: 1 = appartiene, 0 = altrove
- $K+1$ maschere per $K$ oggetti

### Contorni
- Lista ordinata e chiusa di punti
- 3D: nuvola di punti → mesh triangolarizzata

## Conversione tra Rappresentazioni

**Maschera → Contorno**: distance transform, gradiente, Canny

**Contorno → Maschera**: Even-odd rule (fence algorithm)
- Semiretta dal punto: intersezioni dispari = interno
- MATLAB: `poly2mask`

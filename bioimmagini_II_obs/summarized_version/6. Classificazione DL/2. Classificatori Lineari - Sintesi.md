# Classificatori Lineari - Sintesi

## k-Nearest Neighbor (k-NN)

1. Trova k immagini più vicine nel training set
2. Votazione: maggioranza relativa delle label

**Limiti**: memoria intero training set, complessità alta

## Classificatore Lineare

**Score function**: $f(I, W, b) = WI + b$
- W: matrice pesi (K×D)
- b: bias vector

**Vantaggio**: singola moltiplicazione matriciale → veloce

## SVM (Hinge Loss)

$$L_i = \sum_{j \neq y_i} \max(0, s_j - s_{y_i} + \Delta)$$

- Loss = 0 se score corretto supera altri di almeno Δ
- **Regolarizzazione L2**: $\lambda \|W\|^2$

## Softmax (Cross-Entropy)

$$L_i = -\log\left(\frac{e^{f_{y_i}}}{\sum_j e^{f_j}}\right)$$

**Softmax**: mappa score in probabilità $[0,1]$, somma = 1

## Gradient Descent

$$W := W - \eta \frac{\partial L}{\partial W}$$

| Variante | Usa |
|----------|-----|
| **Batch GD** | Tutto training set |
| **Mini-batch** | Sottoinsieme |
| **SGD** | Singola immagine |

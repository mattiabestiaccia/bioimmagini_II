# Introduzione alla Classificazione - Sintesi

## Problema

Associare un'immagine a un'**etichetta (label)** = visual class

## Approccio Classico vs Data-Driven

| Approccio | Metodo | Problema |
|-----------|--------|----------|
| **Classico** | Segmentazione → estrazione struttura → confronto libreria | Creare libreria di strutture |
| **Data-Driven** | Machine Learning su esempi | Richiede dataset etichettato |

## Workflow ML

1. **Training Set**: immagini già classificate
2. **Addestramento**: classificatore impara
3. **Test Set**: valutazione prestazioni (mai visto durante training)

## Overfitting e Validation Set

- **Overfitting**: modello memorizza training, non generalizza
- **Validation Set**: per ottimizzare iperparametri
- **Test Set**: usare UNA SOLA VOLTA alla fine

## Cross-Validation (K-Fold)

1. Dividere dati in K parti
2. Per ogni fold: usarlo come validation, altri K-1 come training
3. Media delle prestazioni sui K esperimenti

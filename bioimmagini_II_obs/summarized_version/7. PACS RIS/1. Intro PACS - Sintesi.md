# Introduzione PACS/RIS - Sintesi

## Vantaggi Immagini Digitali in Radiologia

- **Minor costo**: elimina stampe radiografiche
- **Archiviazione compatta**: DVD, server vs spazi fisici
- **Conservazione contenuto informativo**: profondità segnale preservata
- **Metadati solidali**: dati paziente nel DICOM
- **Elaborazione senza conversione A/D**
- **Accesso via rete**: database centralizzati (PACS)

## Conversione Analogico-Digitale

- Imaging analogico: rivelazione e visualizzazione su stesso supporto (pellicola)
- Conversione: campionamento spaziale + quantizzazione scala grigi
- Dispositivi moderni: **nativamente digitali** (fosfori a memoria, sensori stato solido)

## Standard DICOM

- Formato standard per immagini diagnostiche
- Unico con valore legale
- Contiene immagine + metadati

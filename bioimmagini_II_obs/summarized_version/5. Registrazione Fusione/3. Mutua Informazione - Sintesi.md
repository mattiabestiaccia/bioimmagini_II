# Mutua Informazione - Sintesi

## Fondamenti

- $P(X)$: distribuzione probabilità = istogramma normalizzato
- $P(X,Y)$: distribuzione congiunta = istogramma 2D

**Indipendenza**: $P(X,Y) = P(X) \cdot P(Y)$

## Entropia di Shannon

$$H(X) = -\sum_{x_i} P(X=x_i) \cdot \log_2 P(X=x_i)$$

- Alta entropia = distribuzione uniforme (casualità)
- Bassa entropia = distribuzione concentrata (ordine)

## Entropia Congiunta

$$H(X,Y) = -\sum_{x,y} P(X,Y) \cdot \log_2 P(X,Y)$$

**Indipendenza**: $H(X,Y) = H(X) + H(Y)$

## Mutua Informazione (MI)

$$MI(X;Y) = H(X) + H(Y) - H(X,Y)$$

**Interpretazione**: quantità di informazione che Y contiene su X

## Proprietà MI

| Proprietà | Formula |
|-----------|---------|
| Non negativa | $MI \geq 0$ |
| Simmetrica | $MI(X;Y) = MI(Y;X)$ |
| Indipendenza | $MI = 0 \iff$ indipendenti |
| Auto-info | $MI(X;X) = H(X)$ |
| Limite | $MI \leq \min[H(X), H(Y)]$ |

## Vantaggio Chiave

**Non assume linearità** nella relazione tra variabili (a differenza della correlazione)

## Registrazione

- Immagini allineate → istogramma congiunto con picchi diagonali → MI alta
- Immagini disallineate → istogramma diffuso → MI bassa
- **Ottimizzare T per massimizzare MI**

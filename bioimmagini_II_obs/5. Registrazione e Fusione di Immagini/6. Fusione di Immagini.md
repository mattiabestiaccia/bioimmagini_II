## Fusione di Immagini

Una volta ottenuta la **registrazione**, è spesso necessario presentare all'utente una rappresentazione combinata delle due immagini, che fornisca la migliore informazione clinica. Questo processo è detto **fusione di immagini** (image fusion).

> [!info] Obiettivo Clinico
> La fusione permette di combinare informazioni **anatomiche** (alta risoluzione spaziale, es. CT/MRI) con informazioni **funzionali** (metaboliche, es. PET/SPECT) per:
> - Localizzazione precisa di lesioni
> - Planning chirurgico e radioterapico
> - Follow-up terapeutico

---

## 1. Classificazione delle Tecniche di Fusione

Le tecniche di fusione si classificano in base al **dominio** in cui operano:

| Categoria | Tecniche | Caratteristiche |
|-----------|----------|-----------------|
| **Dominio Spaziale** | Weighted Average, Min/Max, IHS, PCA | Operano direttamente sui pixel |
| **Dominio Frequenze** | Piramidi, Wavelet | Decompongono in bande di frequenza |
| **Basate su Regioni** | Segmentazione + fusione selettiva | Trattano regioni diverse in modo diverso |

---

## 2. Tecniche nel Dominio Spaziale

### 2.1 Fusione RGB Semplice

Considerato che le immagini biomediche sono a singolo canale, un metodo molto semplice è creare una immagine a colori **RGB a tre canali** e scrivere i valori delle due immagini in canali RGB diversi, dopo opportuna normalizzazione a 8 bit.

```matlab
% MATLAB - Funzione imshowpair
imshowpair(img_anatomica, img_funzionale, 'falsecolor');
```

> [!example] Esempio Pratico
> In figura osserviamo un fantoccio TAC e la stessa immagine ruotata:
> - La funzione riempie i canali R e B con la seconda immagine (viola)
> - Il canale G con la prima immagine (verde)
> - Aree sovrapposte: livelli di grigio (RGB uguali)
> - Aree non coincidenti: viola o verde

### 2.2 Alpha Blending (Overlay)

Una tecnica più evoluta è la **fusione con overlay**, in cui una immagine viene usata come sfondo e la seconda viene sovrapposta con un grado di trasparenza $\alpha$ (blending).

$$I_{fusa}(x,y) = \alpha \cdot I_1(x,y) + (1-\alpha) \cdot I_2(x,y)$$

dove $\alpha \in [0,1]$.

Tipicamente:
- **Sfondo** (scala di grigi): immagine anatomica (CT, MRI T1)
- **Overlay** (falsi colori): immagine funzionale (PET, SPECT)

```matlab
% MATLAB - Alpha blending
imfuse(img_CT, img_PET, 'blend', 'Scaling', 'independent');
```

> [!tip] Interattività
> L'utente può regolare $\alpha$ in tempo reale per trovare il bilanciamento ottimale tra informazione anatomica e funzionale.

### 2.3 Fusione Minimo/Massimo

Tecniche che selezionano per ogni pixel il valore minimo o massimo tra le immagini:

$$I_{max}(x,y) = \max(I_1(x,y), I_2(x,y))$$
$$I_{min}(x,y) = \min(I_1(x,y), I_2(x,y))$$

| Metodo | Applicazione |
|--------|--------------|
| **Maximum** | Evidenziare strutture brillanti da entrambe le immagini |
| **Minimum** | Evidenziare regioni scure (es. cavità) |

### 2.4 Fusione IHS (Intensity-Hue-Saturation)

Trasforma le immagini nello spazio colore IHS:

1. L'immagine anatomica fornisce l'**Intensity** (dettaglio spaziale)
2. L'immagine funzionale fornisce **Hue** e **Saturation** (informazione metabolica)
3. Si riconverte in RGB

**Vantaggi:** Preserva il dettaglio spaziale dell'immagine ad alta risoluzione.

### 2.5 Fusione PCA (Principal Component Analysis)

1. Calcola le componenti principali delle due immagini impilate
2. La prima componente principale (PC1) cattura l'informazione comune
3. Le componenti successive catturano le differenze

$$PC_1 = w_1 \cdot I_1 + w_2 \cdot I_2$$

dove i pesi $w_1, w_2$ sono determinati dalla matrice di covarianza.

## 3. Tecniche nel Dominio delle Frequenze

### 3.1 Piramide Laplaciana

Scompone ogni immagine in una **piramide multi-risoluzione**:

1. Costruisci la piramide Gaussiana (sottocampionamento progressivo)
2. Calcola la piramide Laplaciana (differenze tra livelli)
3. Fondi i livelli corrispondenti delle due piramidi
4. Ricostruisci l'immagine fusa

```
Livello 0 (alta freq): dettagli fini → seleziona da immagine ad alta risoluzione
Livello n (bassa freq): struttura globale → media pesata
```

> [!info] Vantaggio
> Permette di combinare i **dettagli ad alta frequenza** dell'immagine anatomica con le **strutture a bassa frequenza** dell'immagine funzionale.

### 3.2 Fusione Wavelet

La trasformata wavelet discreta (DWT) decompone l'immagine in:
- **Coefficienti di approssimazione** (LL): bassa frequenza
- **Coefficienti di dettaglio** (LH, HL, HH): alta frequenza in diverse direzioni

**Strategia di fusione:**

| Banda | Strategia | Motivazione |
|-------|-----------|-------------|
| LL (approssimazione) | Media pesata | Combina informazione globale |
| LH, HL, HH (dettagli) | Maximum assoluto | Preserva edges e dettagli |

```matlab
% MATLAB - Fusione wavelet
[cA1, cH1, cV1, cD1] = dwt2(img1, 'db4');
[cA2, cH2, cV2, cD2] = dwt2(img2, 'db4');

% Fusione coefficienti
cA_fused = 0.5*cA1 + 0.5*cA2;
cH_fused = max(abs(cH1), abs(cH2)) .* sign(cH1 + cH2);
% ... analogamente per cV, cD

img_fused = idwt2(cA_fused, cH_fused, cV_fused, cD_fused, 'db4');
```

## 4. Tecniche di Visualizzazione Multimodale

Oltre alla fusione vera e propria, esistono tecniche di **visualizzazione comparativa**:

### 4.1 Checkerboard

Divide lo schermo in una griglia a scacchiera, alternando le due immagini:

```
┌───┬───┬───┬───┐
│ A │ B │ A │ B │
├───┼───┼───┼───┤
│ B │ A │ B │ A │
├───┼───┼───┼───┤
│ A │ B │ A │ B │
└───┴───┴───┴───┘
```

**Uso:** Verifica qualità della registrazione (bordi devono coincidere).

```matlab
% MATLAB
imshowpair(img1, img2, 'checkerboard');
```

### 4.2 Split-Screen (Curtain)

Una linea verticale/orizzontale divide le due immagini:

```
┌─────────┬─────────┐
│         │         │
│  Img A  │  Img B  │
│         │         │
└─────────┴─────────┘
```

**Uso:** L'utente può trascinare la linea per esplorare.

### 4.3 Synchronized Scrolling

Per volumi 3D: navigazione sincronizzata tra i dataset con cursori crosshair allineati.

## 5. Applicazioni Cliniche

### 5.1 Oncologia: PET-CT

> [!example] Staging Tumorale
> La fusione PET-CT è lo standard per:
> - **Staging** di tumori (es. linfoma, polmone)
> - **Localizzazione** di metastasi
> - **Valutazione risposta** alla terapia

| Modalità | Informazione |
|----------|--------------|
| **CT** | Anatomia, dimensioni lesione, calcificazioni |
| **PET (FDG)** | Metabolismo glucidico, attività tumorale |

La fusione permette di:
1. Distinguere lesioni attive da cicatrici
2. Localizzare anatomicamente le aree di uptake
3. Guidare biopsie

### 5.2 Cardiologia: CT-PET e SPECT-CT

In figura osserviamo ricostruzioni 3D da TAC cardiaca:
- (a, b) Rendering 3D con stenosi coronarica (freccia)
- (c) Angiografia di conferma
- (d) PET cardiaca (perfusione miocardica)
- (e) **Fusione CT-PET**: dimostra l'effetto della stenosi sulla perfusione (miocardio giallo invece che arancio-rosso)

*(Eur. J. Nucl. Med. Mol. Imaging 36(12), 2027–2033 © 2009)*

> [!example] Software CardIQ Fusion (GE)
> Workflow SPECT-CT:
> - **A:** Registrazione SPECT ↔ CT
> - **B:** Ricostruzione albero coronarico (CT)
> - **C:** Mappa perfusione (SPECT) su geometria ventricolare (CT)
> - **D:** Fusione finale CT-SPECT
>
> *(Eur J Nucl Med Mol Imaging (2014) 41 (Suppl 1):S91–S103)*

### 5.3 Neurologia: MRI Multimodale

| Sequenza | Informazione | Applicazione |
|----------|--------------|--------------|
| **T1** | Anatomia (sostanza grigia/bianca) | Base anatomica |
| **T2/FLAIR** | Edema, lesioni | Sclerosi multipla |
| **DWI** | Diffusione, ischemia acuta | Stroke |
| **fMRI** | Attivazione cerebrale | Planning chirurgico |

La fusione fMRI-T1 è essenziale per il **planning neurochirurgico**:
- Localizza aree eloquenti (motorie, linguaggio)
- Evita danni durante resezione tumorale

### 5.4 Radioterapia: Planning

> [!warning] Importanza Clinica
> La fusione PET-CT è fondamentale per la definizione del **GTV** (Gross Tumor Volume):
> - CT: delinea anatomia e densità per calcolo dose
> - PET: identifica tessuto metabolicamente attivo

**Workflow:**
1. CT di simulazione (paziente immobilizzato)
2. PET diagnostica
3. Registrazione rigida/deformabile
4. Contornamento GTV sulla fusione
5. Calcolo piano di trattamento

## 6. Metriche di Qualità della Fusione

Come valutare oggettivamente la qualità di un'immagine fusa?

### 6.1 Metriche con Riferimento

Quando esiste un'immagine "ground truth":
- **PSNR** (Peak Signal-to-Noise Ratio)
- **SSIM** (Structural Similarity Index)
- **RMSE** (Root Mean Square Error)

### 6.2 Metriche Senza Riferimento

Per fusione multimodale (no ground truth):

| Metrica | Formula | Interpretazione |
|---------|---------|-----------------|
| **Entropia** | $H = -\sum p_i \log_2 p_i$ | Contenuto informativo |
| **MI** (Mutua Informazione) | $MI(A,F) + MI(B,F)$ | Informazione preservata |
| **$Q^{AB/F}$** | Gradiente-based | Trasferimento bordi |
| **SF** (Spatial Frequency) | $\sqrt{RF^2 + CF^2}$ | Dettaglio spaziale |

> [!tip] Interpretazione
> - Entropia alta → immagine ricca di dettagli
> - MI alta → informazione delle sorgenti preservata
> - $Q^{AB/F}$ vicino a 1 → bordi ben trasferiti

## 7. Considerazioni Pratiche

### 7.1 Pre-processing

Prima della fusione:
1. **Normalizzazione intensità** (0-1 o 0-255)
2. **Ricampionamento** alla stessa griglia
3. **Registrazione** accurata (errore < 2mm per applicazioni cliniche)

### 7.2 Scelta della Tecnica

| Scenario | Tecnica Consigliata |
|----------|---------------------|
| Visualizzazione rapida | Alpha blending |
| Preservare dettagli spaziali | Wavelet, Laplacian |
| Evidenziare differenze | Checkerboard, RGB |
| Analisi quantitativa | Mantieni immagini separate |

### 7.3 Software

| Software | Tipo | Caratteristiche |
|----------|------|-----------------|
| **MATLAB** | Generale | imfuse, imshowpair |
| **3D Slicer** | Open source | Moduli registrazione + fusione 3D |
| **ITK-SNAP** | Open source | Overlay, segmentazione |
| **MIM** | Commerciale | Standard radioterapia |
| **Syngo.via** (Siemens) | Commerciale | Workstation multimodale |

## 8. Limitazioni e Sfide

1. **Qualità della registrazione**: errori di registrazione producono artefatti nella fusione
2. **Differenze di risoluzione**: necessità di ricampionamento (potenziale perdita di dettaglio)
3. **Standardizzazione**: manca uno standard per rappresentare immagini fuse in DICOM
4. **Quantificazione**: la fusione è principalmente qualitativa; per analisi quantitative si usano le immagini originali

> [!warning] Attenzione Clinica
> L'immagine fusa non deve mai sostituire l'analisi delle immagini originali per diagnosi quantitative (es. SUV in PET).

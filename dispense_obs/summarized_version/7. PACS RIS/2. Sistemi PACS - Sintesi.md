# Sistemi PACS - Sintesi

## Definizione

**PACS** (Picture Archiving and Communication Systems): sistema integrato per gestione digitale immagini diagnostiche

## Componenti PACS

| Componente | Funzione |
|------------|----------|
| **Modalità** | Acquisizione immagini DICOM |
| **Image Server/DB** | Accesso strutturato (query/retrieve) |
| **Archivio** | Storage fisico (RAID) |
| **Backup** | Copia sicurezza (DVD, MO, DAT) |
| **Workstation** | Visualizzazione, elaborazione, refertazione |
| **Stampanti** | Stampa pellicola/carta |
| **Rete** | Connessione TCP/IP |

## Gerarchia DICOM

```
PAZIENTE (PatientID)
└── STUDIO (StudyUID)
    └── SERIE (SeriesUID)
        └── IMMAGINI (InstanceUID)
```

## Sistema RAID

| Tipo | Capacità | Ridondanza |
|------|----------|------------|
| **RAID 0** | N × disco | Nessuna |
| **RAID 1** | 1 disco | Massima (tutti i dischi) |
| **RAID 3** | (N-1) × disco | 1 guasto tollerato |
| **RAID 6** | (N-2) × disco | 2 guasti tollerati |

**Principio**: controllo di parità XOR

## Dimensionamento PACS

$$D = T_{on-line} \sum_{m=1}^{M} D_m N_m$$

$$N_{dischi} = \lceil D/C_d \rceil + K$$

- $D_m$: dimensione esame per modalità
- $N_m$: esami/mese per modalità
- $T_{on-line}$: tempo archiviazione on-line
- $K$: dischi ridondanza

## Workstation

- **Monitor**: 2-3 Mpixel per tomografiche, 5 Mpixel per mammografia
- **DICOM client**: scarica da archivio
- **DICOM server locale**: immagini in elaborazione
- **Secondary DICOM**: risultati elaborazione

## Backup

| Supporto | Capacità | Caratteristiche |
|----------|----------|-----------------|
| **DVD** | 4+ GB | Economico, delicato |
| **Magneto-Ottico** | 1.2-5 GB | Robusto, costoso |
| **DAT** | Alto | Accesso sequenziale (lento) |

## RIS (Radiology Information System)

- Gestione workflow radiologico
- Accettazione paziente
- Assegnazione ID
- Integrazione con PACS

# Dal Post-processing all'Analisi dell'Immagine - Sintesi

## Tre Livelli di Analisi

- **Qualitativa**: descrittiva, osservazione visiva (es. "ventricolo di normali dimensioni")
- **Semi-quantitativa**: classificazione per classi (severo/medio/lieve/assente)
- **Quantitativa**: indici numerici estratti da algoritmi (es. "VTD 66 ml/m²")
  - Maggiore oggettività e precisione
  - Valori tradotti in classi secondo linee guida

## Cambio di Paradigma

- Alcune acquisizioni destinate **solo all'elaborazione** (non esame visivo)
  - Immagini PC (Phase Contrast): velocità flusso
  - Immagini T1/T2/T2* multiecho: caratterizzazione tessuti
- Terminologia moderna: **Medical Image Analysis**
- Software di elaborazione = **parte strutturale** del processo diagnostico

## Normativa Dispositivi Medici

**D.Lgs 37/2010** (direttiva UE 93/42/CEE):
- Software elaborazione immagini diagnostiche = **dispositivo medico**
- Richiede certificazione CE

**Tipologie software:**
1. **Stand-alone**: programmi elaborazione (autonomi)
2. **Integrati**: in dispositivi di acquisizione

**Nota**: software cartella clinica ≠ dispositivo medico

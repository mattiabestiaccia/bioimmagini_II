# Certificazione Dispositivi Medici - Sintesi

## Requisiti per Certificazione

1. Validazione clinica adeguata
2. Manualistica completa
3. Documento gestione del rischio

## Classificazione Software

| Tipo | È Dispositivo Medico? |
|------|----------------------|
| Informazioni diagnostiche | **Sì** |
| Visualizzazione immagini | **Sì** |
| Analisi/segmentazione | **Sì** |
| Cartella clinica (archivio) | No |

## Classi di Rischio

| Classe | Danno Potenziale | Esempio |
|--------|------------------|---------|
| **A** | Nessun danno | Viewer semplice |
| **B** | Lesioni non gravi | Supporto decisionale |
| **C** | Morte/lesioni gravi | Pianificazione chirurgica |

## Procedura di Certificazione

1. **Verifica** se è dispositivo medico
2. **Destinazione d'uso** (quando usare, limiti)
3. **Classe di rischio** (tabelle normativa)
4. **Progettazione ISO** + fascicolo tecnico
5. **Valutazione conformità** (ente notificato per B/C)
6. **Manuale installazione**
7. **Manuale d'uso**
8. **Procedure manutenzione**

## Riferimenti Normativi

- **MDR UE 2017/745**: Medical Device Regulation
- **IEC 62304**: Ciclo di vita software
- **ISO 14971**: Gestione rischio
- **ISO 13485**: Sistema qualità

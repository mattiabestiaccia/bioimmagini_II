# Fusione di Immagini - Sintesi

## Classificazione Tecniche

| Dominio | Tecniche |
|---------|----------|
| **Spaziale** | Alpha blending, Min/Max, IHS, PCA |
| **Frequenze** | Piramidi, Wavelet |
| **Regioni** | Segmentazione + fusione selettiva |

## Tecniche Principali

### Alpha Blending
$$I_{fusa} = \alpha \cdot I_1 + (1-\alpha) \cdot I_2$$

- Sfondo (grigio): anatomica (CT/MRI)
- Overlay (colori): funzionale (PET/SPECT)

### Min/Max
- $I_{max}$: evidenzia strutture brillanti
- $I_{min}$: evidenzia cavità

### Wavelet
- Decompone in: LL (bassa freq), LH/HL/HH (alta freq)
- LL: media pesata
- Dettagli: maximum assoluto (preserva edges)

## Visualizzazione Multimodale

- **Checkerboard**: scacchiera alternata
- **Split-screen**: linea divisoria mobile
- **Synchronized scrolling**: navigazione sincronizzata 3D

## Applicazioni Cliniche

| Ambito | Fusione | Uso |
|--------|---------|-----|
| **Oncologia** | PET-CT | Staging, localizzazione metastasi |
| **Cardiologia** | SPECT-CT | Correlazione stenosi-perfusione |
| **Neurologia** | fMRI-T1 | Planning neurochirurgico |
| **Radioterapia** | PET-CT | Definizione GTV |
